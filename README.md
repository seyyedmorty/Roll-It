##  About the App

**Roll It** is a lightweight and minimalistic dice roller app.  
Perfect for quick rolls, testing randomization, or just having a little fun 😄

###  Features

-  Roll a dice with a single tap  
-  Instant animation and result  
-  Built entirely with **Jetpack Compose**  
-  Simple, clean UI

---

##  Tech Stack

- **Kotlin**
- **Jetpack Compose**
- **Material 3**
- **State Management with Compose**
- **Random number generation**
